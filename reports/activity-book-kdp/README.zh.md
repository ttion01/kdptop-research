## 核心结论

1. 截至2026年11月16日，亚马逊美国站综合活动书细分市场共有3183本在榜书籍，估算日销量2185本，细分评分76分，在1715个细分市场中排名第17。
2. 截至2026年11月16日，综合活动书样本的评论数中位数为3条，少于50条评论的书占78.9%，月销100本以上的书仅占3.1%。
3. 截至2026年11月16日，综合活动书样本中独立出版占69.0%，过去一年出版的新书占60.4%，说明自出版作者仍在持续进入这一市场。
4. 截至2026年11月16日，亚马逊美国站综合活动书价格中位数为10.95美元，P25为9.99美元，P75为13.9美元，样本页数中位数为100页。
5. 截至2026年11月16日，圣诞节综合活动书评分74分，冬季综合活动书评分70分，评论中位数仅6条。这两个季节细分的评论进入门槛相对较低。

## 市场有多大

亚马逊美国站综合活动书细分市场共有3183本书，其中纸书2837本、Kindle电子书346本，涉及1732个类目。榜单包含畅销榜和新品榜，分别收录1970本和1546本。市场估算日销量为2185本，细分评分76分，在1715个细分市场中排名第17。

样本月销量中位数为6本，说明市场总销量主要由少数畅销书贡献。3183本书覆盖成人、儿童、节日及不同活动主题，市场规模足以容纳多种内容方向。不过，细分市场的总销量不能直接用来估算普通新书的销售表现。

不同搜索词的需求差异较大。halloween activity book 搜索量为9721次，商品数10414个，平均价格5.6美元；surgery recovery activity book 搜索量1766次，商品数625个，平均价格14.99美元；christmas activity book 搜索量669次，商品数30312个，平均价格5.99美元。easy crafts for kids 搜索量为613次，商品数达到125706个。

## 竞争和评论门槛

样本评论数中位数为3条。评论少于10条的书有1928本，10至50条的有582本，50至100条的有181本，100至500条的有330本，500条及以上的有162本。少于50条评论的书占78.9%，说明大量在榜产品尚未积累较多评论。不过，评论数量少并不意味着产品能够获得稳定销量。

月销100本以上的书占3.1%。其中，月销100至300本的有73本，300至1000本的有20本，1000本及以上的有5本。独立出版占69.0%，过去一年出版的新书占60.4%，说明市场仍有新书和独立出版产品进入的空间，但达到较高月销量的产品数量有限。样本中93.8%的产品属于KDP可行范围。

## 值不值得做

综合活动书市场规模较大，独立出版占比较高，细分评分76分，在1715个细分市场中排名第17。独立出版占69.0%，过去一年出版的新书占60.4%，评论少于50条的书占78.9%，说明新作者仍有进入榜单的空间。圣诞节综合活动书和冬季综合活动书可以作为独立方向评估。冬季方向的评论中位数只有6条，但样本仅有84本，判断时需要考虑样本规模。

这一市场适合围绕明确人群、用途或主题开发内容，例如成人益智活动、儿童不同年龄段的活动书，以及节日活动书。宽泛的综合活动书虽然总量较大，但头部书的估算月销量明显高于样本月销量中位数6本，月销100本以上的书仅占3.1%。头部10本均非独立出版，成熟品牌和长期积累的评论仍然构成竞争压力。

现有数据没有提供统一的旺季月份或上架窗口，因此无法据此确定圣诞节或冬季活动书的具体出版日期。

## 常见问题

### 综合活动书在亚马逊美国站有多大的市场？

截至2026年11月16日，综合活动书共有3183本在榜书籍，估算日销量2185本，在1715个细分市场中排名第17。样本月销量中位数为6本，市场整体销量不能直接作为单本新书的销量预期。

### KDP独立出版作者进入综合活动书市场容易吗？

截至2026年11月16日，综合活动书样本中独立出版占69.0%，过去一年出版的新书占60.4%。少于50条评论的书占78.9%，说明新书有进入榜单的空间。但月销100本以上的书仅占3.1%，进入榜单和获得稳定销量之间仍有明显差距。

### 综合活动书定价多少比较合适？

截至2026年11月16日，样本价格中位数为10.95美元，P25为9.99美元，P75为13.9美元。8至10美元区间有1003本，10至13美元区间有803本，样本页数中位数为100页。定价时还需要结合页数核算印刷成本。

### 综合活动书有哪些值得关注的细分方向？

圣诞节综合活动书评分74分，共379本，评论中位数14条；冬季综合活动书评分70分，共84本，评论中位数仅6条。成人综合活动书评分72分，共648本，6-8岁综合活动书评分71分，共1142本。

## 方法与局限

细分里的书是 2026-11-16 前 3 天出现在亚马逊美国站畅销榜或新品榜上、且 AI 分类落在这个细分的书，共 3,183 本。评论、销量和价格分布用其中 KDPTop 有详细数据的 3,183 本计算；销量是根据销售排名估算的。

榜单数据来自 KDPTop 每天对亚马逊美国站全部图书和 Kindle 类目畅销榜、新品榜的抓取；书籍信息来自榜单卡片、书籍页面和 Keepa；搜索量来自第三方关键词工具，是估算值。成人内容类目不在统计里。

局限：榜单反映排名而不是真实销量，销量和销售额都是根据排名估算的；KDPTop 没有见过的书不在统计里。
