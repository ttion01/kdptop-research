## 核心结论

1. 截至2026年11月16日，亚马逊美国站记录本细分市场共有4161本上榜图书，估算日销量为1028本，细分评分67分，在1715个细分市场中排名第160位。
2. 截至2026年11月16日，记录本榜单中有2819本书的评论数少于10条，86.8%的样本评论数少于50条，评论数中位数为9条，整体评论门槛较低。
3. 截至2026年11月16日，记录本样本中93.0%为独立出版，34.5%的图书在过去一年出版，但月销超过100本的图书仅占0.5%。
4. 2026年10月至11月的亚马逊搜索数据显示，bowling score book 获得1321次搜索和122次购买，gestational diabetes log book 获得916次搜索和49次购买。不同具体用途的搜索需求差异明显。
5. 截至2026年11月16日，记录本价格中位数为$9.99，P25为$7.99，P75为$9.99，页数中位数为110页。8.5x10.98和5.98x9.02是最常见的开本规格。

## 市场有多大

亚马逊美国站记录本细分市场共有4161本图书，其中纸书4130本、Kindle电子书31本，涉及1478个类目。当前榜单估算日销量为1028本，细分评分67分，在1715个细分市场中排名第160位。榜单涵盖健康、旅行、记分、商业、运动、密码和组织管理等用途，产品数量较多，但需求分布在不同的具体使用场景中。

榜单统计期为2026年10月18日至11月16日，销量估算数据覆盖2026年10月27日至11月16日。4161本是当前榜单和新品榜的样本数量，不代表亚马逊全部记录本商品数量。

## 竞争和评论门槛

评论数分布显示，2819本书少于10条评论，794本有10至50条，250本有50至100条，218本有100至500条，80本达到500条及以上。样本评论数中位数为2条，86.8%的图书少于50条评论。

月销量方面，4016本低于30本，123本处于30至100本，16本达到100至300本，5本达到300至1000本，没有图书达到1000本以上。月销超过100本的图书仅占样本的0.5%。

独立出版占比为93.0%，过去一年出版的新书占34.5%。KDP作者已经大量进入这一市场，新书也在持续增加，但稳定获得较高销量的图书数量有限。评论数量较少说明积累评论的竞争门槛较低，不能据此判断订单容易获得。低评论数与低销量同时存在于大量样本中。

## 值不值得做

记录本是一个规模较大、独立出版参与度高的成熟细分市场，评分67分，排名第160位。93.0%的样本来自独立出版，评论数中位数仅2条，过去一年出版的新书占34.5%，说明KDP作者仍有进入空间。适合重点研究的方向包括记分、账单管理、密码管理、健康追踪和特定职业记录，这些用途都能围绕明确的记录需求设计内页。Clever Fox Password Book 和账单记录本的估算销量显示，明确的产品功能和持续使用需求可以支撑较高销量。

市场的主要问题是销量分布高度集中。样本中4016本月销低于30本，月销超过100本的图书只有0.5%。价格中位数为$9.99，主要价格区间集中在$8-$10，普通空白记录本的定价空间有限。选题时需要核对内页是否符合目标用途，并结合关键词搜索量和搜索结果产品数量判断竞争情况。

目前没有明确的记录本季节峰值数据，无法据此制定节日上架窗口。依靠通用封面和简单空白内页竞争的作者，面临的销量分布并不理想。有专业知识、能够设计实用记录模板的作者，可以优先测试具体用途明确的产品方向。

## 常见问题

### 亚马逊美国站记录本市场有多大？

截至2026年11月16日，记录本细分市场共有4161本上榜图书，其中纸书4130本、Kindle电子书31本。估算日销量为1028本，在1715个细分市场中排名第160位。

### 记录本市场的竞争激烈吗？新书容易进入吗？

样本评论数中位数为2条，86.8%的图书少于50条评论，独立出版占比为93.0%。过去一年出版的新书占34.5%，但月销超过100本的图书仅占0.5%。评论门槛较低，说明新书有进入空间，但不能据此认为销量容易突破。

### KDP记录本应该定价多少？常见页数是多少？

价格中位数为$9.99，P25为$7.99，P75为$9.99，其中$8-$10区间有1744本。页数中位数为110页，最常见的开本是8.5x10.98和5.98x9.02。

### 哪些记录本细分方向更值得研究？

记录本（成人）评分67分，记录本（老年人）和记录本（情侣 / 夫妻）均为61分。情侣 / 夫妻方向只有57本，中位评论数4条；记录本（老师）中位评论数3条、记录本（学生）中位评论数2条，两者评分均为54分。这些方向可以结合具体关键词需求进一步验证。

## 方法与局限

细分里的书是 2026-11-16 前 3 天出现在亚马逊美国站畅销榜或新品榜上、且 AI 分类落在这个细分的书，共 4,161 本。评论、销量和价格分布用其中 KDPTop 有详细数据的 4,161 本计算；销量是根据销售排名估算的。

榜单数据来自 KDPTop 每天对亚马逊美国站全部图书和 Kindle 类目畅销榜、新品榜的抓取；书籍信息来自榜单卡片、书籍页面和 销售排名历史；搜索量是估算值。成人内容类目不在统计里。

局限：榜单反映排名而不是真实销量，销量和销售额都是根据排名估算的；KDPTop 没有见过的书不在统计里。
